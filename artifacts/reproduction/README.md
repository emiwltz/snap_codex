# Earlier local reproduction snapshots

`v3.1-core/` and `v3.1-publication/` are retained outputs produced before the first
manuscript. They are useful for tracing the numerical history, but are not a new
campaign and are not the active reproduction destination.

Use the root README and `scripts/reproduce.py` for current work. New runs go below
ignored `artifacts/runs/`; the manuscript's retained aggregate evidence is in
`paper/results/`. These older snapshots stay in place and byte-identical so their
recorded manifests and external references continue to resolve. They are omitted
from the curated presentation bundle to avoid duplicate result entry points.
