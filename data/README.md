# SNAP v3.1 reference data

Raw evidence of the SNAP v3.1 pilot: 2,700 responses from six language-model
endpoints, two LLM-judge codes per response, the final scores used in the
analyses, 30 manual adjudications and 200 historical human-validation labels.

| `manual_sample_coded.csv` | `5cd1f17e2a54d0b0117ab1c0fce11a689e1d65d798c3cbe0c1ac980796a7bb54` |

- [Data dictionary](DICTIONARY.md): tables, columns, codes, counts and missing
  values.
- [Data guide](../docs/DATA.md): what each file is evidence of, joins,
  provenance and the limits of the human-labelled sample.
- [Coding provenance](../docs/CODING_PROVENANCE.md): who produced the manual
  labels and under which conditions, as far as it is known.

The files are reference inputs. Do not open them with the pipeline's
`SoulBenchDB`, which initializes and migrates on open; use the reproduction
script, which works on consistent backups (see
[REPRODUCING](../docs/REPRODUCING.md)), or a read-only SQLite connection:

```python
import sqlite3
conn = sqlite3.connect("file:data/snap_poc_v3_1.db?mode=ro", uri=True)
```
